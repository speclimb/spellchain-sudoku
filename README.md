# 連鎖詠唱ナンプレ

数字の起点を選び、連鎖で戦う日本語ブラウザゲーム。Phaser / TypeScript / Vite。PCとスマホ縦画面に対応しています。

**[ブラウザで遊ぶ](https://speclimb.github.io/spellchain-sudoku/)**

リポジトリ: [speclimb/spellchain-sudoku](https://github.com/speclimb/spellchain-sudoku)

## 起動

Node.js 24以降を使用します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。配布用ファイルは `npm run build` で `dist/` に生成され、通常の静的ホスティングに配置できます。サーバー処理やアカウント、外部の画像・フォント配信は不要です。

スマホ実機で開く場合は同じLAN上で `npm run dev -- --host 0.0.0.0` を実行し、PCのLANアドレスの5173番ポートへアクセスします。開発サーバーをインターネットへ公開しないでください。

## 遊び方

1. 術師を選んで冒険開始。青緑の枠の数字は、候補が1つで正解が確定しています。
2. マスを選ぶと連鎖経路、ダメージ、被ダメージが表示されます。起点は何度でも選び直せます。選択中は●、他の選べる起点は○と細い枠で示し、連鎖経路の中でも見分けられます。上位・弱点のレンズの★は現在のモードで最長になる全起点です。
   「連鎖のしくみ」を開くと、前へ・次へで1マスずつ確認できます。水色の枠が直前のマス、金の枠が次のマス、明るい帯がつながる行・列・区画です。予告の確認で手数や魔力は消費しません。
3. 「詠唱する」で確定。Lv.1では起点＋自動3マス、導火術師はさらに＋1マス。術式レベルが1上がるごとに自動入力も1回ずつ増えます。
4. 行・列・3×3区画の完成は、短い全画面の魔法カットインと追加ダメージ。✧は弱点、◇は守護＋6。同じシートで獲得した守護は蓄積し、完成時を含む毎回の反撃を軽減します。残り数マスを埋める手でも守護が消えません。
5. 魔力8または五の護符の無料回数があると、固有スキルで未確定マスからも始動できます。無料回数を先に使い、魔力と蓄電を温存します。スキルの手では充電されません。
6. 上位・長い導火線があれば、シート完成時の残り自動入力回数で次のシートへ連鎖します。攻撃と反撃は全シートの詠唱後に各1回。その詠唱中の最大シート守護値を使い、足し合わせません。未所持なら従来どおり完成・反撃後に新シートへ移ります。
7. シート完成と敵撃破で術式レベル＋1。レベルごとに自動入力＋1回、攻撃倍率＋0.2、最大HP＋4、HPを最大10回復。敵撃破ごとに3択で新しい力を選びます。5・10・15戦目以降も5戦ごとにボスが登場し、固有スキルか上位遺物を選べます。連戦は終わらず、後半は敵の攻撃が成長を上回ります。HPが尽きた時点でスコアと撃破数を記録します。敵撃破による残りマスの一掃はシート完成の成長に含みません。

PCでは矢印キーで盤面のフォーカスを移動し、Enterで起点を選択できます。入力の確定は別の詠唱ボタンで行います。考えている間は敵が動かず、時間制限や時間による得点差はありません。

連鎖は毎回「直前に埋めたマス」と同じ行・列・3×3区画にある確定マスから、縦の距離＋横の距離が最短のものへ進みます。同距離なら上の行、次に左の列を優先。最初から確定していたマスも対象です。自動入力回数が0になるか、次につながる確定マスがなくなると終了し、その理由も予告に表示します。導火術師はLv.1で通常最大5連鎖、スキルで最大9連鎖。Lv.10では14／18連鎖になり、遺物でさらに増えます。上位・長い導火線があれば36連鎖を越えて続きます。連鎖数そのものに36／72などの上限はなく、残り自動入力回数か接続先がなくなると終了します。

未所持の遺物が少なくなると、術式レベルを上げる「術式の鍛錬」、最大HPと現在HPを増やす「生命の器」、全回復の選択肢で報酬を補います。遺物を集め終えても毎戦3択が続きます。上位7種を揃えた後のボスでは「鍛錬／次の5戦は開幕魔力8／次の5戦は被ダメージ25％軽減」の3択になります。加護は同種を重ねず残り5戦へ更新し、二の護符との合計軽減は60％までです。

## 遺物・ボス・一詠全成の成長ルール

- **一筆の杖**：各詠唱の最初の3マスが生んだ基本・完成・弱点ダメージを2倍。4マス以上つないでも効果は残ります。上位版は最初の5マスへ置き換え、2倍を重ね掛けしません。
- **蓄電石**：通常詠唱の魔力＋2。上限8を超えた分を最大2だけ別に蓄え、スキル使用直後にその分を魔力へ戻します。スキル自身では充電も超過蓄積もしません。蓄えは戦闘を越えて保持します。
- **素数の護符**：二・三・五・七は対応する数字を実際に埋めた詠唱につき、各効果を独立に1回だけ抽選します。取得1／2／3回目で30／45／60％、上位化で確率はそのまま効果だけ置き換えます。盤面を越えて同じ数字を何度埋めても抽選は増えません。
  - 二：守護で引いた後の反撃を25％軽減。上位は50％。加護との合計は60％までで、軽減後は端数を切り上げます。
  - 三：通常攻撃部分が1.5倍、上位2倍。完成加算は増幅しません。
  - 五：次のスキルを無料で使える回数を1回、上位2回（保有上限も1／2）。無料スキル使用中・無料回数を持っている間は五を抽選しません。満タンの魔力より無料回数を優先するため、無料回数→残した魔力で連続スキルが使えます。
  - 七：次の詠唱の自動入力を＋7、上位＋14。予約は1回分で加算されず、現在の詠唱の経路には影響しません。
- **上位・弱点のレンズ**：現在の通常／スキルモードで、盤面越えを含む最長連鎖になる起点すべてに★を表示します。「最長N連鎖・候補Mか所」も表示。最長連鎖と最大ダメージは同じとは限らず、選択時の攻撃予告は残ります。基本の選択可能表示には遺物が不要です。
- **上位・長い導火線**：完成時の残り自動入力を新しいシートへ持ち越します。新シート内で最長につながる確定起点を選び、同長なら上→左。その最初の入力も自動1回を使います。数字の巡回順などは追加せず、行・列・区画による既存の接続を保ちます。
- **黄金のインク**：最終攻撃ダメージから得るスコアを1.5倍。ダメージへの効果はありません。敵撃破の固定500点は別に加算します。
- **ボス報酬**：5・10・15戦目……は未強化なら固有スキル強化1枠、上位遺物を最大2枠。上位は一筆・二・三・五・七・レンズ・導火線の7種で、通常版未所持でも取得できます。未取得の上位レンズ／導火線が候補に残る限り、そのどちらかを最低1枠保証します。取得は強制しません。全上位取得後は鍛錬・魔力の加護・守護の加護の3択です。
- **固有スキルランク**：術式レベルとは別に1→2まで。導火術師はスキル中、次につながる確定マスがなくなり自動入力回数が残っていれば、直前と同じ数字の空きマスへ1回だけ飛び火（回数1を消費、距離・上・左の順）。紋章術師はスキルの完成ダメージ3→4倍、蓄光術師はスキルの攻撃倍率2→2.5倍。通常詠唱にランク強化の追加効果はありません。

**シート完成の追加ダメージ**は、シートごとにそのシートの通常攻撃を D、そのシートでこの手に実際に埋めたマス数を N、シートの初期空きマス数を B として floor(D × 0.25 × N / B) を計算し、合計します。全詠唱ダメージを各シートへ重複計上しません。現在の全問題は45個の初期数字と36個の空きマスなので B=36です。最後の1マスだけなら1/36分、手付かずの36マスすべてを1回で埋めた「一詠全成」なら最大25％を加算します。敵撃破後の見た目の一掃は含みません。一詠全成は強い単発の光・音・明示的な内訳で祝い、短縮・動きを抑える・消音設定にも対応します。

処理順序は「各マスの基本・完成・弱点（一筆を適用）→術式・スキル・通常倍率→整数化した D →護符の1回抽選→シート完成の追加分→攻撃スコア→撃破判定→未撃破なら反撃→生存時の成長・回復」です。完成追加分を護符で再増幅しません。上位導火線では複数シートを跨げます。自動入力回数と術式倍率は詠唱開始時に固定し、共鳴・再燃・ランク2導火術師の飛び火は詠唱全体で従来の回数まで。成長は生存した詠唱の終了後に完成枚数＋撃破1レベルをまとめて反映し、その場の自動入力を補充しません。1マスの基本ダメージは10、12……80で止めますが、連鎖数と追加ダメージは伸び続けます。敵HPを超えても詠唱を完走し、超過分をスコアにします。次の敵へ攻撃せず、ボス報酬も飛ばしません。

予告は護符の抽選を一切実行せず、確定ダメージと発動確率・発動時ダメージを表示します。盤面越えの予告では複製した問題乱数を使い、本番状態を消費しません。最長起点は関連する盤面・資源・モードごとにキャッシュし、選択や描画のたびに全探索しません。発動次第で撃破できる場合は被ダメージ・回復・成長も幅を示し、不発なら敗北する手を安全とは表示しません。確率判定は保存された冒険のシードと全体の詠唱回数、効果ごとの固定領域から決まり、予告の回数や順序、再読み込みで結果が変わりません。問題と報酬の乱数列から分離しています。

敵HPは最初の4戦が1400／2200／3200／4600、5戦目が6500。6戦目以降は d=戦数−5 として 6500＋1300d＋150d²＋100 max(0,d−10)²。旧後半の1戦ごと1.5倍から緩やかな曲線に変更しました。攻撃力は5＋floor(d/2)＋floor(max(0,d−5)²/8)、ボスと番人は3手ごとに強攻撃。護符の大当たりを前提にせず、決定的な攻撃・長い連鎖と既存の成長で進めることを自動攻略で確認します。

## 効果音と公開用素材

外部SEはCC0素材のみを採用しています。KenneyのInterface Sounds・Impact Soundsと、JaggedStoneのMagic Spell SFXから12音を同梱し、操作・詠唱開始・完成魔法・打撃・防御・シート完成・成長で使い分けます。連鎖の上昇音は合成音を重ねます。音素材は合計約76KBで、音がオンの状態で最初に操作したときに読み込みます。消音は演出中でも即座に反映し、読み込みに失敗した場合は合成音で続行します。

[出典・加工内容・ライセンス](THIRD_PARTY_NOTICES.md)と素材ごとのURL・ハッシュを保存しています。配布用にも`audio-licenses/`へクレジットとCC0原文を含め、設定画面から参照できます。

Phaserなど配布するライブラリの著作権・ライセンス通知は [`software-licenses/`](public/software-licenses/CREDITS.txt) にまとめ、公開サイトにも同梱しています。

ビルドは相対URLを使用するため、GitHub Pagesのリポジトリ配下にも配置できます。音源を含めて`dist/`一式を配信してください。実行時に素材サイトへの接続は不要です。

## 実装済みの内容

- シングルだけで解ける、一意解の9×9問題30問。毎回数字・行列・転置を変換し、30問を使い切るまで元問題を重複させず、以降は新しい順序で継続。境目でも同じ問題が続きません。
- 終わりのない連戦、3キャラ、13遺物、累計敵撃破による解放。5戦ごとのボスと上位報酬。6種類の敵の姿が再登場し、後半ほどHPと攻撃力が増加。最高撃破数とベストスコアを記録。
- 複数シートにまたがる戦闘と術式レベルによる成長。現在のシート数、自動入力の成長分、攻撃倍率、成長の予告を表示。
- 連鎖が伸びるほど強まる光の軌跡・火花・音、攻撃とスコアのポップアップ、被弾の赤い画面効果、完全防御の青い盾。行・列は光線、区画は魔法陣、同時完成は複合の全画面カットイン。多数の完成はまとめて表示し、長い連鎖でも演出時間が伸び続けない構成。短縮・動きを抑える設定に対応。
- 予告と実行で共通の決定的な連鎖処理。最短距離、同距離なら上・左に連鎖。確率効果は詠唱の確定時だけ解決し、予告では確定分と発動時の上限を分けて表示。
- 一手内の完成・弱点・共鳴・再燃・倍率・充電の処理。守護はシート内で蓄積して毎回の反撃に適用し、シート切替でリセット。「守護の紋章」の完成1単位につき＋3も同様。完成時も反撃は残るため、敵の攻撃力が蓄積守護を超えればダメージを受けます。
- 超過ダメージを含む得点。一掃による追加得点・充電・効果発動はありません。
- 自動保存、中断・再開、ベスト記録、図鑑、初回ガイド、消音・短縮・動きを抑える設定。
- シート完成と敵撃破時の成長・HP回復、各巡のボスと番人の3手ごとの強攻撃。盤面完成時の反撃でHPが0になった場合は敗北します。

保存はこのブラウザのlocalStorage内だけです。端末間同期はありません。行動を解決してから描画するため、連鎖中にページを再読み込みしても同じ手や報酬を再処理しません。サイトデータ削除で記録は消えます。解放済みアイテムの抽選プールは冒険開始時に固定されます。以前の保存データは盤面・敵HP・魔力・報酬を保持して新しい形式へ移行します。旧保存の現在の敵は旧バランスのHPと反撃をそのまま使い、報酬を選んで次の敵へ進む時に新バランスへ切り替わります。旧保存の抽選済み報酬と問題・報酬の乱数状態は再抽選しません。

## 検証

```sh
npm test
npm run build
npm run test:browser
```

ブラウザテストはWindowsではMicrosoft Edge、それ以外ではPlaywrightのChromiumを非表示で使用します。Windows以外では先に `npx playwright install --with-deps chromium` を実行してください。ローカル開発サーバーを自動起動し、PCとスマホ相当の表示幅、通常入力とスキル、7戦目以降への継続と敗北、連鎖・攻撃・防御の演出、シート終盤の守護維持、シート切替時の守護リセット、保存・再開を確認します。音源12点の読み込み・デコード・再生開始、演出中の消音、音源欠損時の続行も検証します。スクリーンショットは `.runtime/screenshots/` に保存されます。

ビルド後に `node scripts/smoke-audio-pages.mjs` を実行すると、専用の一時サーバーで `/spellchain-sudoku/` 配下の配信を確認できます。JavaScript・CSS・音源・ライセンスの読み込みと実際の1手を検証し、終了時にそのサーバーを閉じます。

`npm run generate:puzzles` で収録問題を同じ固定シードから再生成・検証できます。

成長調整の自動攻略は、各キャラ4シード（21〜24）の計12ランで「三の護符」を抽選プールから除外して検証します。今回のサンプルは47〜61撃破、111〜160手、全キャラで最大36連鎖へ到達した後、実際の反撃で敗北しました。5・10・15戦目のボスへ大当たりなしで到達できる確認です。これは予告を比較して手を選ぶ自動攻略であり、人間のプレイ時間・難易度の保証ではありません。詳細はテストが生成する `.runtime/character-balance-sample.json` に記録します。

追加の回帰テストでは、護符の発動／不発と予告の幅、予告による乱数消費ゼロ、再開後の同一結果、蓄電・再取得・上位化の上限、ボス報酬の不足枠、一詠全成と撃破一掃の区別、旧敵HPの移行を確認します。

## GitHub Pagesへの公開

`main` へのpushで [GitHub Actions](https://github.com/speclimb/spellchain-sudoku/actions) がルールテスト、ビルド、ブラウザテスト、リポジトリ配下での音源・ライセンス配信確認を実行し、成功した `dist/` をGitHub Pagesに公開します。Pull Requestでは同じ検証だけを実行します。

公開元はリポジトリの Settings → Pages → Build and deployment → Source で **GitHub Actions** を指定します。手動で再公開するときは Actions の **Test and deploy GitHub Pages** から **Run workflow** を実行できます。

## 構成

- `src/game/`: 描画に依存しない盤面、戦闘、報酬、進行、保存の処理。
- `src/ui/`: Phaserの盤面と演出、操作用のHTMLグリッド、連鎖音。
- `src/main.ts` / `src/style.css`: タイトル、戦闘HUD、報酬、結果、図鑑、設定とレスポンシブ表示。
- `tests/`: ルール検証とブラウザ操作テスト。

公開インターフェースは `startRun(save, character, seed)`、`previewAction(run, cell, skill)`、`resolveAction(run, action)`、`dispatch(save, action)`。状態はシリアライズ可能で、処理は元の状態を変更しません。行動にはrevisionが必要で、古い行動の再適用は拒否します。

固定のクリア戦数や10分の制限はありません。後半は成長した長い連鎖で大量のマスを埋め、さらに速く強くなる敵にどこまで挑めるかを競います。自動攻略では成長・連戦の継続・実際の反撃による敗北を確認し、到達戦数や各戦の手数を記録します。難易度と爽快感の最終調整は人によるプレイでも確認します。

## 長い詠唱と保存

詠唱の記録はシート別の開始盤面と経路区間で構成し、マスを「通算シート＋座標」で識別します。新しいシートの同じ座標も別の入力です。全結果を演出前に保存し、途中の再読み込み・演出スキップ・動きを抑える設定でも入力・成長・報酬を二重に処理しません。一詠全成はそのシートの初期空き36マスを今回だけで埋めた場合に限り、途中まで埋まったシートの仕上げや敵撃破時の一掃とは区別して祝います。旧セーブのHP・抽選済み3択・問題／報酬乱数は維持し、新しい護符は未抽選の報酬から参加します。
