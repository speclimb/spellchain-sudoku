# 連鎖詠唱ナンプレ

数字の起点を選び、連鎖で戦う日本語ブラウザゲーム。Phaser / TypeScript / Vite。PCとスマホ縦画面に対応しています。

## 起動

Node.js 24以降を使用します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。配布用ファイルは `npm run build` で `dist/` に生成され、通常の静的ホスティングに配置できます。サーバー処理やアカウント、外部の画像・フォント配信は不要です。

スマホ実機で開く場合は同じLAN上で `npm run dev -- --host 0.0.0.0` を実行し、PCのLANアドレスの5173番ポートへアクセスします。開発サーバーをインターネットへ公開しないでください。

## 遊び方

1. 術師を選んで冒険開始。青緑の枠の数字は、候補が1つで正解が確定しています。
2. マスを選ぶと連鎖経路、ダメージ、被ダメージが表示されます。起点は何度でも選び直せます。
   「連鎖のしくみ」を開くと、前へ・次へで1マスずつ確認できます。水色の枠が直前のマス、金の枠が次のマス、明るい帯がつながる行・列・区画です。予告の確認で手数や魔力は消費しません。
3. 「詠唱する」で確定。Lv.1では起点＋自動3マス、導火術師はさらに＋1マス。術式レベルが1上がるごとに自動入力も1回ずつ増えます。
4. 行・列・3×3区画の完成は、短い全画面の魔法カットインと追加ダメージ。✧は弱点、◇は守護＋6。同じシートで獲得した守護は蓄積し、完成時を含む毎回の反撃を軽減します。残り数マスを埋める手でも守護が消えません。
5. 魔力が8たまると、固有スキルで未確定マスからも始動できます。スキルの手では充電されません。
6. 1枚埋めても敵のHPが残っていれば、蓄積した守護で反撃を受けてから次のシートへ。守護だけを0に戻し、同じ敵のHP、魔力、反撃の周期を引き継いで戦います。
7. シート完成と敵撃破で術式レベル＋1。レベルごとに自動入力＋1回、攻撃倍率＋0.2、最大HP＋4、HPを最大10回復。敵撃破ごとに3択で新しい力を選びます。6体の敵を越えても連戦は続き、周回を重ねると敵の強さがこちらの成長を上回ります。HPが尽きた時点でスコアと撃破数を記録します。敵撃破による残りマスの一掃はシート完成の成長に含みません。

PCでは矢印キーで盤面のフォーカスを移動し、Enterで起点を選択できます。入力の確定は別の詠唱ボタンで行います。考えている間は敵が動かず、時間制限や時間による得点差はありません。

連鎖は毎回「直前に埋めたマス」と同じ行・列・3×3区画にある確定マスから、縦の距離＋横の距離が最短のものへ進みます。同距離なら上の行、次に左の列を優先。最初から確定していたマスも対象です。自動入力回数が0になるか、次につながる確定マスがなくなると終了し、その理由も予告に表示します。導火術師はLv.1で通常最大5連鎖、スキルで最大9連鎖。Lv.10では14／18連鎖になり、遺物でさらに増えます。1枚の空きマス数とつながる確定マスの有無が実際の連鎖数の上限です。

未所持の遺物が少なくなると、術式レベルを上げる「術式の鍛錬」、最大HPと現在HPを増やす「生命の器」、全回復の選択肢で報酬を補います。遺物を集め終えても毎戦3択が続きます。

## 実装済みの内容

- シングルだけで解ける、一意解の9×9問題30問。毎回数字・行列・転置を変換し、30問を使い切るまで元問題を重複させず、以降は新しい順序で継続。境目でも同じ問題が続きません。
- 終わりのない連戦、3キャラ、12遺物、累計敵撃破による解放。6体の敵が周回で再登場し、後半ほどHPと攻撃力が増加。最高撃破数とベストスコアを記録。
- 複数シートにまたがる戦闘と術式レベルによる成長。現在のシート数、自動入力の成長分、攻撃倍率、成長の予告を表示。
- 連鎖が伸びるほど強まる光の軌跡・火花・音、攻撃とスコアのポップアップ、被弾の赤い画面効果、完全防御の青い盾。行・列は光線、区画は魔法陣、同時完成は複合の全画面カットイン。多数の完成はまとめて表示し、長い連鎖でも演出時間が伸び続けない構成。短縮・動きを抑える設定に対応。
- 予告と実行で共通の決定的なルール処理。最短距離、同距離なら上・左に連鎖。
- 一手内の完成・弱点・共鳴・再燃・倍率・充電の処理。守護はシート内で蓄積して毎回の反撃に適用し、シート切替でリセット。「守護の紋章」の完成1単位につき＋3も同様。完成時も反撃は残るため、敵の攻撃力が蓄積守護を超えればダメージを受けます。
- 超過ダメージを含む得点。一掃による追加得点・充電・効果発動はありません。
- 自動保存、中断・再開、ベスト記録、図鑑、初回ガイド、消音・短縮・動きを抑える設定。
- シート完成と敵撃破時の成長・HP回復、各巡の番人と古竜の3手ごとの強攻撃。盤面完成時の反撃でHPが0になった場合は敗北します。

保存はこのブラウザのlocalStorage内だけです。端末間同期はありません。行動を解決してから描画するため、連鎖中にページを再読み込みしても同じ手や報酬を再処理しません。サイトデータ削除で記録は消えます。解放済みアイテムの抽選プールは冒険開始時に固定されます。以前の保存データは盤面・敵HP・魔力・報酬を保持して新しい形式へ移行します。

## 検証

```sh
npm test
npm run build
npm run test:browser
```

ブラウザテストはWindowsのMicrosoft Edgeを非表示で使用します。ローカル開発サーバーを自動起動し、PCとスマホ相当の表示幅、通常入力とスキル、7戦目以降への継続と敗北、連鎖・攻撃・防御の演出、シート終盤の守護維持、シート切替時の守護リセット、保存・再開を確認します。スクリーンショットは `.runtime/screenshots/` に保存されます。

`npm run generate:puzzles` で収録問題を同じ固定シードから再生成・検証できます。

## 構成

- `src/game/`: 描画に依存しない盤面、戦闘、報酬、進行、保存の処理。
- `src/ui/`: Phaserの盤面と演出、操作用のHTMLグリッド、連鎖音。
- `src/main.ts` / `src/style.css`: タイトル、戦闘HUD、報酬、結果、図鑑、設定とレスポンシブ表示。
- `tests/`: ルール検証とブラウザ操作テスト。

公開インターフェースは `startRun(save, character, seed)`、`previewAction(run, cell, skill)`、`resolveAction(run, action)`、`dispatch(save, action)`。状態はシリアライズ可能で、処理は元の状態を変更しません。行動にはrevisionが必要で、古い行動の再適用は拒否します。

固定のクリア戦数や10分の制限はありません。後半は成長した長い連鎖で大量のマスを埋め、さらに速く強くなる敵にどこまで挑めるかを競います。自動攻略では成長・連戦の継続・実際の反撃による敗北を確認し、到達戦数や各戦の手数を記録します。難易度と爽快感の最終調整は人によるプレイでも確認します。
